# Прогнозно-аналитическая система мониторинга и прогнозирования загрузки городских парковочных пространств

## Описание проекта

Проект посвящён разработке прогнозно-аналитической системы для мониторинга и прогнозирования уровня загрузки городских парковочных пространств.

Система предназначена для сбора данных о состоянии парковок, анализа динамики загрузки и построения прогноза будущей занятости парковочных мест.

## Предметная область

Городская парковочная инфраструктура.

## Прогнозируемый показатель

Процент загрузки парковочного пространства.

## Источники данных

1. Open Data Hub Mobility API — данные о состоянии парковок.
2. Open-Meteo API — погодные данные.
3. Календарные данные — временные признаки.
