# Прогнозно-аналитическая система мониторинга и прогнозирования загрузки городских парковочных пространств

## Описание проекта

Проект посвящён разработке системы для мониторинга и прогнозирования уровня загрузки городских парковочных пространств.

## Цель проекта

Создание системы, которая собирает данные о состоянии парковок, анализирует динамику загрузки и прогнозирует будущую занятость парковочных мест.

## Источники данных

- Open Data Hub Mobility API;
- Open-Meteo API;
- календарные данные.

## Этап разработки

Постановка задачи и подготовка структуры проекта.
