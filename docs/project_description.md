# Постановка задачи

## Мониторинг и прогнозирование уровня загрузки городских парковочных пространств на основе исторических данных и внешних факторов

## 1. Предметная область

Предметной областью проекта является городская парковочная инфраструктура.

В современных городах уровень загрузки парковочных пространств изменяется в зависимости от времени суток, дня недели, погодных условий и других внешних факторов. Неравномерное распределение спроса приводит к периодам высокой нагрузки на отдельные парковочные зоны и снижению эффективности использования парковочной инфраструктуры.

В рамках проекта рассматривается задача разработки прогнозно-аналитической системы, которая позволяет анализировать текущее состояние парковочных пространств и прогнозировать изменение уровня их загрузки.

Основным объектом исследования являются городские парковки, для которых доступны данные о количестве занятых парковочных мест и общей вместимости объектов.

## 2. Прогнозируемый показатель

Основным прогнозируемым показателем является уровень загрузки парковочного пространства.

Показатель рассчитывается как отношение количества занятых парковочных мест к общей вместимости парковки:

Occupancy = Occupied / Capacity × 100%

где:

- Occupied — количество занятых парковочных мест;
- Capacity — общее количество парковочных мест.

Использование относительного показателя позволяет сравнивать между собой парковочные объекты различного размера.

В рамках проекта планируется прогнозировать процент загрузки парковочного пространства на ближайший временной интервал на основе исторических данных и внешних факторов.

## 3. Практическая задача

Практическая задача проекта заключается в создании системы, позволяющей получать, анализировать и прогнозировать данные о загрузке городских парковочных пространств.

Разрабатываемая система должна позволять:

- отслеживать текущее состояние парковок;
- анализировать изменение уровня загрузки во времени;
- выявлять периоды максимальной нагрузки;
- прогнозировать будущую занятость парковочных мест.

Полученная аналитическая информация может использоваться для повышения эффективности управления парковочной инфраструктурой и принятия решений на основе данных.

## 4. Пользователи системы

Основными пользователями разрабатываемой системы являются:

- операторы парковочной инфраструктуры, которым необходим анализ текущей загрузки и прогноз изменения спроса;
- городские службы, занимающиеся управлением транспортной инфраструктурой;
- аналитики, исследующие использование парковочных пространств.

## 5. Источники данных

Для реализации проекта планируется использовать несколько разнородных источников данных.

### 5.1. Open Data Hub Mobility API

Основным источником данных является открытый API Open Data Hub Mobility.

Источник содержит информацию о состоянии парковочных объектов и временные данные об их загрузке.

Используемые данные:

- идентификатор парковки;
- время измерения;
- количество занятых парковочных мест;
- общая вместимость парковки;
- информация о расположении объекта.

Полученные данные будут использоваться для формирования временного ряда загрузки парковочных пространств.

Источник:

https://docs.opendatahub.com/use-data/time-series-api/reference/

### 5.2. Open-Meteo API

В качестве дополнительного источника используются исторические погодные данные.

Погодные условия могут влиять на использование парковочной инфраструктуры, поэтому они будут учитываться как внешние факторы при анализе и прогнозировании.

Используемые показатели:

- температура воздуха;
- количество осадков;
- облачность;
- скорость ветра.

Источник:

https://open-meteo.com/en/docs

### 5.3. Календарные данные

Дополнительно будут использоваться календарные признаки:

- день недели;
- выходной или рабочий день;
- праздничные дни.

Данные признаки позволят учитывать регулярные временные закономерности изменения загрузки парковочных пространств.
