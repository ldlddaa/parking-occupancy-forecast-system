# Data

Папка предназначена для хранения данных, используемых в проекте.

## Структура данных

- raw — исходные данные, полученные из внешних источников без изменений;
- processed — обработанные данные, подготовленные для анализа и построения прогнозных моделей.

В дальнейшем здесь будут храниться данные о загрузке городских парковочных пространств, погодные данные и дополнительные признаки.
